# KlipperViewer — real-time application

A browser dashboard for viewing printer state and visualizing G-code.

- Integrated streaming updates through WebSocket APIs.
- Built reactive status and visualization components.
- Added connection-state handling and reconnect behavior.

**Technologies:** Svelte, JavaScript, WebSocket, JSON-RPC, Canvas.

**Scope:** Personal application with private source; requires a configured Moonraker instance.
