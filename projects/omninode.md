# OmniNode — machine learning & backend services

A personal prototype that combines streaming telemetry, machine-learning anomaly detection, and a backend API.

- Generated synthetic data and evaluated an Isolation Forest against known simulation states.
- Connected independent services through MQTT.
- Built a Java/Spring Boot service for storing readings and querying recent data.

**Technologies:** Python, scikit-learn, Java, Spring Boot, C++, MQTT, MySQL.

**Scope:** Personal prototype using synthetic data. Source is private; results do not establish real-world detection accuracy.
